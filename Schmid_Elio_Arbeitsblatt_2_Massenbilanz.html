2 Zweiter Datensatz: Massenbilanz pro Hydrojahr

2.1 Datensatz

Auch dieser Datensatz ist bei GLAMOS verfügbar.Eine Zeile beschreibt einen Gletscher in einem Hydrojahr (jeweils von Oktober bis September). Die Winterbilanz (Bw) ist der Zugewinn durch Schnee bis Ende April, die Sommerbilanz (Bs) der Verlust danach, die Jahresbilanz (Ba) die Summe der beiden. Eine Bilanz von −1000 mm w.e. bedeutet, dass der Gletscher im Mittel über seine Fläche eine Wasserschicht von 1 m verloren hat. Zusätzlich gibt es die Gleichgewichtslinie (ELA), also die Höhe, oberhalb der im Jahr netto Masse zugewinnt, und den Anteil der Fläche oberhalb dieser Linie (AAR).

Abschnitt anzeigen

Die Daten sind bereits sauber: keine fehlenden Werte, ISO-Datum, keine Platzhalter. Es sind nur noch wenige Schritte nötig: Typen setzen, das Jahr (Jahr des Periodenendes) und die Dauer berechnen und die Bilanzen in m w.e. umrechnen, damit sie sich besser lesen lassen.

gl <- roh |>
  mutate(
    across(c(Bw, Bs, Ba, ELA, AAR, area_km2, h_min, h_max), as.numeric),
    across(c(date_start, date_end_winter, date_end), as.Date),
    jahr       = year(date_end),
    dauer_tage = as.numeric(date_end - date_start),
    # Bilanzen in m w.e. (anschaulicher als mm)
    Bw_m = Bw / 1000,
    Bs_m = Bs / 1000,
    Ba_m = Ba / 1000,
    # ELA nicht beobachtbar, wenn der Gletscher gar kein Nährgebiet hat
    # oder die Linie über dem höchsten Punkt liegt: extrapolierter Wert
    ela_extrapoliert = AAR == 0 | ELA > h_max
  ) |>
  select(-Bw, -Bs, -Ba)

2.8.1.1 Iteration 2: Heatmap ab 2000 und ab 1990

Anpassungen: Die erste Version enthielt viele leere Felder, weil einzelne Gletscher erst spät oder mit Lücken gemessen wurden. Code anzeigen 
heatmap_iter2 <- function(daten, von, titel, sortierung = c("bilanz", "messjahr")) {
  sortierung <- match.arg(sortierung)
  raster <- daten |>
    filter(jahr >= von) |>
    complete(glacier_name, jahr = von:max(gl$jahr))

  if (sortierung == "bilanz") {
    # stärkster Verlust (tiefste mittlere Bilanz) oben
    raster <- raster |>
      mutate(glacier_name = fct_reorder(glacier_name, Ba_m, mean, na.rm = TRUE, .desc = TRUE))
  } else {
    # Gletscher mit dem frühesten Messbeginn oben, bei gleichem Beginn der mit mehr Jahren
    reihenfolge <- raster |>
      filter(!is.na(Ba_m)) |>
      group_by(glacier_name) |>
      summarise(erster = min(jahr), n = n(), .groups = "drop") |>
      arrange(desc(erster), n)
    raster <- raster |>
      mutate(glacier_name = factor(glacier_name, levels = reihenfolge$glacier_name))
  }

  ggplot(raster, aes(jahr, glacier_name, fill = Ba_m)) +
    geom_tile(colour = "white", linewidth = 0.3) +
    scale_fill_gradient2(low = "#b2182b", mid = "white", high = "#2166ac",
                         midpoint = 0, limits = c(-3, 3), oob = scales::squish,
                         na.value = "grey70") +
    scale_x_continuous(breaks = seq(von, 2025, 5), expand = c(0, 0)) +
    labs(title = titel, x = "Jahr", y = NULL, fill = "Jahresbilanz\n[m w.e.]",
         caption = "Grau: kein Messwert. Weiss: ausgeglichene Bilanz (0). Farbskala bei ±3 m w.e. begrenzt.") +
    theme(panel.grid = element_blank(), plot.title.position = "plot")
}

2.8.1.2 Iteration 3: Heatmap aller Gletscher seit 1990

auseinander <- function(y, abstand) {
  o <- order(y)
  ys <- y[o]
  for (i in seq_along(ys)[-1]) {
    if (ys[i] - ys[i - 1] < abstand) ys[i] <- ys[i - 1] + abstand
  }
  ys <- ys - (mean(ys) - mean(y))
  y[o] <- ys
  y
}
